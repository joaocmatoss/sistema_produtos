🛒 Sistema de Cadastro e Análise de Produtos

Este projeto foi desenvolvido em Python com o objetivo de simular um sistema simples de cadastro de produtos e análise de preços.

---

🚀 Funcionalidades

✔ Cadastro de 5 produtos  
✔ Armazenamento em dicionário  
✔ Cálculo do valor total dos produtos  
✔ Identificação do produto mais caro  
✔ Identificação do produto mais barato  
✔ Cálculo da média de preços  
✔ Busca de produto pelo nome  
✔ Remoção de produto  

---

🧠 Conceitos utilizados

- Dicionários em Python  
- Estruturas de repetição (`for`)  
- Estruturas condicionais (`if`)  
- Funções  
- Entrada de dados (`input`)  
- Manipulação de dados  
- Métodos como `sum()`, `max()`, `min()`, `get()`
